# Solano Drive

An original 2D top-down open-world crime game built for the make.fun gta6-01 bounty. You play Rico Vega in Puerto Solano, a sun-soaked coastal city split into beach, downtown and suburb districts: steal cars, weave through live traffic and pedestrians, run 8 chained story missions, and outrun a 5-star wanted system with pursuing police. Combat, skid and muzzle effects, synthesized WebAudio sound, a HUD with minimap, a start screen and localStorage saves round it out.
